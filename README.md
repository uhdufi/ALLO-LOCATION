# Alo Location1 — دليل التشغيل والتعديل

## التشغيل والرفع
افتح index.html في متصفح حديث. ارفع index.html وstyle.css وscript.js ومجلد assets معًا إلى نفس المجلد في الاستضافة. جميع مسارات الملفات نسبية، ولا توجد عملية بناء أو قاعدة بيانات مطلوبة.
الخطوط Tajawal وInter تُحمّل من Google Fonts عند توفر الإنترنت؛ توجد خطوط نظام بديلة عند عدم توفره.

## تعديل السيارات والأسعار
في بداية script.js ستجد مصفوفة cars. لكل سيارة:
- price: السعر اليومي بالدرهم. تعديله يحدّث البطاقة والتفاصيل والحساب ورسالة واتساب تلقائيًا. سعر القسم الترحيبي مرتبط بأول سيارة.
- name وimage: الاسم ومسار الصورة.
- transmission: automatic أو manual.
- fuel: petrol أو diesel.
- seats وdoors وluggage: أعداد المقاعد والأبواب والحقائب.
- ac: yes. لإضافة خيار آخر أضف ترجمته في اللغات الثلاث.
- description: مفتاح الوصف في كائن translations.
البيانات الحالية توضيحية ولا تثبت مواصفات السيارات المصوّرة.

## رقم التواصل
غيّر WHATSAPP_NUMBER في بداية script.js إلى الصيغة الدولية دون + أو مسافات، مثل 212607729134.
عند تغيير رقم الوكالة، حدّث أيضًا روابط tel: والأرقام الظاهرة في index.html وأمثلة رسائل الهاتف في translations إذا لزم الأمر.

## اللغات
جميع نصوص الواجهة في translations، بالترتيب ar وfr وen. العربية افتراضية. يُحفظ فقط مفتاح alo-language في localStorage؛ معلومات العميل تبقى في ذاكرة الصفحة ولا تُحفظ تخزينيًا.
تبديل اللغة لا يمسح الحقول أو السيارة المختارة. تحتوي نافذة الحجز على أزرار اللغات أيضًا.

## الحجز
حساب الأيام يعتمد على تواريخ تقويمية عبر UTC، وتاريخ اليوم حسب Africa/Casablanca. يوم البداية إلى اليوم التالي = يوم واحد.
لا يوجد دفع أو إرسال تلقائي أو تأكيد حجز. الزر يفتح رسالة جاهزة في واتساب، وعلى الزبون مراجعتها وإرسالها بنفسه. تؤكد الوكالة التوفر والحجز لاحقًا.

## التحقق المنجز
- فحص صحة JavaScript وتطابق مفاتيح الترجمة.
- اختبار حساب يوم واحد ويومين والسنة الكبيسة والتواريخ غير الصحيحة.
- اختبار الهاتف المحلي والدولي والأرقام العربية والحقول المطلوبة والبداية الماضية والنهاية غير المقبولة.
- اختبار محتوى رسالة واتساب وترميزها والإجمالي باللغات الثلاث دون إرسال رسالة فعلية.
- مراجعة المتصفح: فتح تفاصيل السيارات الثلاث، التبديل بين اللغات مع بقاء الحقول، الإغلاق بـ Escape والفتح بـ Enter، وملخص السعر المباشر.
